
# Web Application

A web application developed as part of a university project using HTML, CSS, JavaScript, and Node.js.

## Technologies Used

- **HTML5** – Web page structure
- **CSS3** – Styling and layout
- **JavaScript** – Client-side functionality
- **Node.js** – Server-side functionality
- **npm** – Package management

## Project Structure

- `css/` – CSS stylesheets
- `html/` – HTML pages
- `js/` – JavaScript files
- `resursi/` – Images and other resources
- `server.cjs` – Node.js server
- `package.json` – Project dependencies
- `package-lock.json` – Dependency lock file

## Installation and Setup

1. Download or clone the repository.
2. Make sure Node.js is installed.
3. Open a terminal in the project directory.
4. Install dependencies using `npm install`.
5. Start the server using `node server.cjs`.
